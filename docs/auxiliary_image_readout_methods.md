# Auxiliary Image-Based Readout Methods

## Methods Paragraph

Auxiliary image-based readout was performed with the repository's template-guided workflow. For each single-layer data ID (1, 3, 4 or 7), the script loaded a root-level JPG image together with a precomputed black-top-hat TIF signal, an ultra-signal TIF image and an `ultra_03_p62` binary candidate mask. The candidate mask was cleaned by small-object removal and morphological closing, then expanded into a loose repair pool using percentile-thresholded top-hat signal and a centre prior. A target-derived frame estimated digit position and scale before template selection. Auxiliary non-blank TIF templates labelled 1/3/4/7 were converted to dark-stroke masks, cropped and matched to the target pool over constrained scale and translation. The highest-scoring template assigned `predicted_digit`; the aligned template then gated component retention and repair. Outputs were binary masks, diagnostic overlays and CSV files reporting digit calls, template paths, scores and alignment metrics.

## Supplementary Methods Version

Auxiliary readout was implemented as a template-guided analysis workflow rather than as a new image-processing method. The batch entry point processes data IDs 1, 3, 4 and 7. For each ID, it reads the corresponding root-level JPG image, a precomputed black-top-hat signal image (`layer{data_id}_black_tophat_signal.tif`), a precomputed ultra-signal image (`layer{data_id}_ultra_signal.tif`) and a binary `ultra_03_p62` candidate mask (`layer{data_id}_ultra_03_p62_bin.png`). The JPG is converted to grayscale or RGB for analysis and visualization, and the binary mask is obtained from an 8-bit grayscale threshold greater than 127. The candidate mask is cleaned by removing small objects and applying binary closing.

The cleaned candidate mask is converted into a target-derived repair pool using the normalized top-hat signal. Candidate components are scored using area, shape, mean signal intensity, proximity to strong strokes and a centre prior; weak and strong signal maps are defined from signal percentiles. A digit frame is estimated from the target pool and signal alone by weighted spatial quantiles, and this frame constrains subsequent template alignment. Auxiliary templates are discovered as non-blank `.tif` files outside `figures` and `results` whose filenames contain 1, 3, 4 or 7. Each template is converted to a dark-stroke representation by background subtraction, thresholding, morphological cleanup, main-group selection and tight cropping. The digit assigned to each template is parsed from its filename.

For readout, every extracted template is resized and correlated against a 384 x 384 target representation over target-constrained scale and translation. The score combines normalized overlap, target pixels inside the template tolerance, template hit density, bidirectional distance-based similarity, and penalties for off-target template pixels, centre offset and scale mismatch. The selected template's digit becomes `predicted_digit`. The selected alignment may be refined over a small grid of scale factors and offsets, except where defaults disable refinement. The aligned template core, tolerance gate and soft template then filter connected components and add repair pixels only where signal and template consistency criteria are satisfied. The script writes final masks and visual audit files and records `predicted_digit`, template path, scores, target frame and alignment parameters in `template_guided_metrics.csv` and `template_match_decisions.csv`.
